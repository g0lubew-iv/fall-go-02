## Поиск максимального значения в большом массиве данных

Это практическое задание призвано закрепить ваши знания по теме «Многопоточность».
Тема, посвящённая многопоточности в Go, довольно обширная, поэтому сложно охватить все её аспекты в одном небольшом проекте.
Самое сложное в многопоточности — это понять, где можно и нужно использовать параллельное выполнение кода.
Это итоговое задание демонстрирует один из возможных сценариев использования многопоточности, и как эта возможность языка ускоряет работу с большими массивами данных.
